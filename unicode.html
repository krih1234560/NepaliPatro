Combine English with Nepali Unicode

Need to keep an English word inside your Nepali sentence? Simply place the English text inside {curly brackets}.

Type
yo {mobile} mero ho.

/

Use / to Separate Letters

If a Nepali letter is incorrectly combined with the preceding letter, use the / key to separate them.

Without separator pratishatko प्रतिशत्को
With separator pratishat/ko प्रतिशतको ✓ Correct
्

Add Halant at the End of a Word

To add a हलन्त at the end of a Nepali word, use the \ backslash key.

Normal bas बस
With Halant bas\ बस्
शब्दको अन्त्यमा हलन्त राख्नको लागि \ अक्षर प्रयोग गर्नुहोस्।
